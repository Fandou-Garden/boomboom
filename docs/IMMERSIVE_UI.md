# 横屏战斗 HUD 与镜头设计

本版按真实横屏手游的拇指操作重排，不再为顶部/底部预留大块布局带，也不使用三张
大卡片或原版空物品格。DOM HUD 固定在屏幕层，Canvas 只负责世界。

## 1. 屏幕分区

| 区域 | 内容 |
| --- | --- |
| 左上 | 小地图：双方位置、当前镜头框、拖动入口、`回到战场` |
| 顶部中央 | 双方头像 + 紧凑血条 + 风向/风力；回合提示在其下方 |
| 左下 | 半透明四向转盘：左右移动、上下调角，中心显示当前角度 |
| 底部中央 | 细长 0–100 力度尺、当前/推荐/上一发标记；下方并排血量、体力（∞）、能量、当前武器 |
| 右上方 | 1–8 战斗道具栏：附加攻击2次、散弹、附加攻击1次、五档伤害增幅 |
| 右下 | `POW` 独立充能键 + 蓝色主键（按住蓄力、松手发射） |
| 右上 | 声音、说明、全屏、换武器、治疗、重开；倒计时开关为可选项，默认关闭 |

- 所有交互控件避开底部手势区和右下平台浮层；主键底边至少留 76 px。
- 667×375 下主键仍为 74×74；技能键不小于 34×34。
- 窄屏先缩装饰、间距和说明文字，不缩主键触控面积。
- 两个角色包围盒与 HUD 的相交面积为 0；右侧技能列另有 20 px 构图偏移保护。

## 2. 镜头

### 瞄准 / 结算：both

- 单一等比 `zoom` 把双方和脚下地形装进画面，角色位于中下部，上方留抛射空间。
- 初始距离 1400 px 不变；不移动出生点、不做 X/Y 非等比拉伸。
- 最小广角 `0.11`，桌面最大 `1.15`；右侧技能栏在窄屏通过构图偏移避让。
- 屏外箭头只在确实看不清时兜底，不作为主要观察手段。

### 飞行：shot

- 跟随炮弹，允许镜头进入天空，双方角色可暂时离屏。
- 进入飞行时锁定缩放，整段飞行只做单向平滑跟拍，不反复 zoom。
- 小地图、顶部血条、转盘、力度尺、技能栏、POW/主键全部保持屏幕原位。
- 飞行中主键禁用并显示“飞行中”，不会二次发射。

### 落地

- 平滑回 `both`：位置 `smoothTime=0.36 s`，缩放 `zoomSmoothTime=0.32 s`。
- 回到下一回合战场视角后，双方重新完整入镜。

### 手动观察

- 小地图拖动只改 `camera.manualX/manualY`，不改变角色、地形或落点记录。
- `回到战场` 清空偏移；飞行开始自动清空偏移，保证跟弹。
- 小地图实时绘制双方点和当前镜头框。

## 3. 瞄准反馈

- 只在角色炮口旁画 44–58 px 短虚线 + 6.5° 扇形，表示方向和仰角。
- 不画完整抛物线，不提供自动瞄准或自动调角。
- 推荐力度用当前角度、实战风力和连续碰撞求解；不可达时显示“推荐 — / 调角或前移”。
- 力度尺同时区分当前蓄力（填充）、上一发（标记）、推荐（标记），并给出明确数字。
- 玩家出手后，上一发站位和实际落点用世界坐标记录并投影到地形；镜头移动不会漂移，
  电脑出手不会覆盖。

## 4. 安全区

- 使用 `env(safe-area-inset-*)`；底部控件至少留 34 px，主键至少 76 px。
- 竖屏显示旋转提示并暂停；不把横屏 HUD 强行塞进竖屏。
- 最窄横屏 667×375 已验证主键无遮挡、双方不被控件压住。
